# Fullstack Learning Project – Angular (PrimeNG) & Spring Boot (JPA/Hibernate)

Hallo! 
Ich bin Max Schneider und dieses Projekt ist aus meinem Wunsch entstanden, **Fullstack-Entwicklung** besser zu verstehen – insbesondere die Kombination aus:

- **Angular** für das Frontend
- **PrimeNG** für UI-Komponenten
- **Spring Boot** für das Backend
- **JPA/Hibernate** für Datenbankzugriffe

Das Projekt ist nicht produktiv gedacht, sondern dient ausschließlich als **Lern- und Übungsprojekt**, um moderne Webentwicklung end-to-end zu verstehen.

---

##  Ziel des Projekts

Ich wollte lernen:

- Wie man ein Angular-Frontend mit Routing, Services, Models und PrimeNG-Komponenten aufbaut
- Wie man ein Spring Boot API erstellt
- Wie man Entities, Repositories und Services mit **JPA/Hibernate** modelliert
- Wie Frontend und Backend sauber miteinander kommunizieren (REST)
- Wie man CRUD-Operationen von der Datenbank bis zum UI umsetzt

---

##  Technologien
